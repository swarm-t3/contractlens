ContractLens

Before you approve, deposit or buy: who can mint, pause, blacklist or upgrade this contract, and what does static analysis flag?

Works for any contract with verified source on Sourcify. Proxies are followed to the implementation. A scan takes 5 to 60 seconds.

For AI agents: one paid HTTP call

The full report (every finding with file and line, every privileged function) is an x402 endpoint: $0.01 USDC per call on Base or Arbitrum. No API key, no signup. Your agent pays and gets JSON back.

GET {API}/scan?chainId=8453&address=0x...

With AgentCash: npx agentcash fetch "{API}/scan?chainId=8453&address=0x...". Or any x402 client (@x402/fetch, x402-axios, Python x402). OpenAPI spec: /openapi.json. Free sample: /sample.

Bad input and unverified contracts are rejected before payment. A failed scan is never settled.

What it checks

  • Admin powers: every state-changing function gated by owner/role/admin modifiers or msg.sender checks (mint, pause, blacklist, setFee, upgradeTo...).
  • Upgradeability: proxy type and current implementation (from Sourcify).
  • Static analysis: about 90 Slither detectors (reentrancy, arbitrary ETH sends, unchecked transfers, uninitialized storage, dangerous delegatecall, shadowing...), ranked by impact.

Automated static analysis, not a manual audit. Expect false positives and treat findings as leads to review. Source: github.com/swarm-t3/contractlens. Contact: megafi.app1+contractlens@gmail.com
